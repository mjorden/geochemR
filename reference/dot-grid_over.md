# Regular grid over a set of points

Regular grid over a set of points

## Usage

``` r
.grid_over(x, y, n = 80, expand = 0.05)
```

## Arguments

- x, y:

  Point coordinates.

- n:

  Cells along the longer axis.

- expand:

  Fraction of the range to pad on each side.

## Value

A data frame of grid `x`, `y`.
